# Homelab

Mon homelab personnel : un serveur auto-hébergé, administré en GitOps.

## Stack

- Fedora Server
- k0s (Kubernetes mono-nœud)
- ArgoCD (GitOps)
- Tailscale (réseau privé)
- Hermes (agent d'administration)

## Services

- Uptime Kuma — supervision des services
- Wealthfolio — suivi de patrimoine personnel
